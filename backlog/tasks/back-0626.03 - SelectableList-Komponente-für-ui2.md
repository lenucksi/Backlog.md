## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Baue eine `<SelectableList>`-Komponente — ersetzt `src/ui/components/generic-list.ts` (607 Zeilen).

API:
```typescript
// Single-Select
const selected = await openSelectList<T>({
  items: tasks,
  renderItem: (task) => <TaskRow task={task} />,
})

// Multi-Select (Promise)
const selected = await openMultiSelect<T>({
  items: tasks,
  renderItem: (task) => <TaskRow task={task} />,
})

// Als Komponente (für eingebettete Nutzung)
<SelectableList
  items={filteredTasks}
  renderItem={(task, index, selected) => <TaskRow ... />}
  multiSelect
  selectedIds={selectedIds()}
  onSelect={(ids) => setSelectedIds(ids)}
  onItemConfirm={(task) => openDetail(task)}
/>
```

Features:
- Virtual Scrolling (optional, bei 500+ Items)
- Search/Filter via Input am Kopf
- Multi-Select via Space
- Keyboard-Navigation: j/k, g (top), G (bottom)
- Pagination/Grouping (optional)
- `onBoundaryNavigation` Callback (wrapping prevention)
- Custom Item-Renderer (JSX)
- Checkbox-Stil: `[✓]` / `[ ]` Prefix
- Fokus-Management: Tab fokussiert Liste, dann Navigation
