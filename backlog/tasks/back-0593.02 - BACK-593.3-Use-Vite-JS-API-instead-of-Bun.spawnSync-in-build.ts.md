## Problem

`scripts/build.ts` invokes Vite via subprocess:

```typescript
const viteResult = Bun.spawnSync(["bun", "x", "vite", "build"], {
    env: { ...process.env, NODE_ENV: "production" },
});
```

This is fragile:
- **Blocks event loop** - spawnSync pauses Bun for 1+ seconds while Vite builds
- **No progress output** - Vite normally writes progress to stderr, but spawnSync swallows it
- **No build metadata** - chunk sizes, warnings, module graph info are lost
- **Indirection** - "bun x vite build" adds subprocess overhead

Vite exports a programmatic JS API that provides type safety, error reporting, and build statistics.

## Location

- File: scripts/build.ts
- Lines: 25-31 (vite build), 33-39 (bun compile - keep as-is)
