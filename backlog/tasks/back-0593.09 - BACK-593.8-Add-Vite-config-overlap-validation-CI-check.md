## Problem

The blank page bug (June 2026, BACK-592) was caused by Vite config where build.rollupOptions.external had an extension pattern overlapping with a custom transform plugin. Rollup deferred to external over transform, emitting raw import statements.

This bug can recur silently if external patterns overlap with custom transform extensions. No build-time error is raised.

### Goal
Add CI/build-time validation that detects overlap.

## Location
- New file: scripts/validate-vite-config.ts
- Or inline in scripts/build.ts
