## Abhängigkeiten

- **BACK-0637.04**: Liefert Audit-Bestätigung (Freigabe zum Pushen)

## Implementation Steps

1. Backup: `git branch backup/pre-squash-$(date +%Y%m%d)` und `git tag pre-squash-$(date +%s)`
2. Rebase-Todo generieren: `bash scripts/generate-rebase-todo.sh`
3. Rebase starten: `git rebase -i 1576fb17`
4. Editor schließen (:q!), dann Todo ersetzen: `cp rebase-todo.txt .git/rebase-merge/git-rebase-todo`
5. Rebase fortsetzen: `git rebase --continue`
6. Bei Konflikten: `git add <file>` → `git rebase --continue`. Bei unlösbaren Konflikten: `git rebase --abort` → Plan anpassen.
7. Ergebnis prüfen: `git log --oneline 1576fb17..HEAD` → erwartet `25 ± 3` Commits
8. Jede Commit-Message prüfen: hat portierte Gruppen (G22, G23, G24) die `Based-on:` + `Co-authored-by:` Footer?
9. Push: `git push fork main --force-with-lease`

## Fehlerbehandlung

- Rebase schief: `git rebase --abort` → zurück zu backup/pre-squash-*
- force-with-lease Fehler: `git fetch fork` → erneut versuchen
- Konflikte nicht lösbar: aborten, Script anpassen, erneut starten
