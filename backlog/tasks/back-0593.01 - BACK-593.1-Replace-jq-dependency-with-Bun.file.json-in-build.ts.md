## Problem

`scripts/build.ts:20` reads the package version using `jq`, an external CLI tool:

```typescript
const ver = Bun.spawnSync(["jq", "-r", ".version", "package.json"]).stdout.toString().trim();
```

**jq is NOT guaranteed on any platform:** not on Windows, often not on minimal Docker/CI images, and not in every macOS or Linux setup. If absent, the spawn returns empty stdout, version becomes `""`, and `--version` output silently shows nothing.

Bun provides native JSON parsing — no external dependency needed.

## Location

- File: `scripts/build.ts`
- Line: 20
- Current: `Bun.spawnSync(["jq", "-r", ".version", "package.json"])`
