## Problem
`runBacklogCli()` in `src/test/commands-cov-helper.ts` mutiert globale Variablen (`process.argv`, `console.log`, `process.exit`, `process.env`). Unter `--parallel` überschreiben sich parallele Aufrufe — Test A setzt `process.argv`, Test B überschreibt, Test A bekommt falsche Args.

**Symptom:** `CommanderError: too many arguments for 'task'. Expected 1 argument but got 2.`

Betrifft 9 Test-Files die `runBacklogCli` nutzen.

## Fix (1 File)

### src/test/commands-cov-helper.ts — komplett ersetzen

Weg mit: `process.argv`-Mutation, `console.log`-Mock, `process.exit`-Mock, `initHelpers()`-Cache.

Rein mit: `program.parseAsync(args, { from: "user" })`, `program.configureOutput()` für Output-Capture, frische Imports pro Aufruf.

```typescript
import { Command } from "commander";
import { BACKLOG_CWD_ENV } from "../utils/runtime-cwd.ts";

export interface CliResult {
	stdout: string;
	stderr: string;
	exitCode: number;
}

export async function runBacklogCli(args: string[], cwd: string): Promise<CliResult> {
	process.env[BACKLOG_CWD_ENV] = cwd;

	const stdout: string[] = [];
	const stderr: string[] = [];
	let exitCode = 0;

	const [initMod, taskMod, configMod] = await Promise.all([
		import("../commands/init.ts"),
		import("../commands/task.ts"),
		import("../commands/config.ts"),
	]);
	const program = new Command();
	program.exitOverride();
	program.configureOutput({
		writeOut: (str: string) => stdout.push(str),
		writeErr: (str: string) => stderr.push(str),
	});

	initMod.registerInitCommand(program);
	taskMod.registerTaskCommand(program);
	configMod.registerConfigCommand(program);

	try {
		await program.parseAsync(args, { from: "user" });
		if (process.exitCode) {
			exitCode = process.exitCode;
		}
	} catch (err: unknown) {
		if (err instanceof Error && (err as { code?: string }).code === "commander.exit") {
			exitCode = (err as { exitCode?: number }).exitCode ?? 1;
		} else if (err instanceof Error && (err as { code?: string }).code === "commander.help") {
			exitCode = 0;
		} else {
			throw err;
		}
	} finally {
		delete process.env[BACKLOG_CWD_ENV];
	}

	return {
		stdout: stdout.join("\n").trim(),
		stderr: stderr.join("\n").trim(),
		exitCode,
	};
}
```

**Wichtig:** `commands-test-helper.ts` (`runBacklogCmd`, für coverage-tests mit `process.exit`-Mock) hat das gleiche Problem — das muss auch gefixt werden, falls es unter `--parallel` läuft. Aber aktuell wird es nur von coverage-Files genutzt die schon via `runBacklogCli` laufen. Prüfung: falls `commands-test-helper.ts` nicht in --parallel Files genutzt wird, ignorieren.
