## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`src/server/router.ts` has 9 duplicate code blocks from repeated route registration patterns:
1. **7 bulk routes** — `.post("/api/tasks/bulk/archive", ...)`, `/bulk/status`, `/bulk/priority`, `/bulk/assignee`, `/bulk/labels`, `/bulk/milestone`, `/bulk/due-date` all share the same shape: `.post(url, handler, { detail: { summary, description, tags: ["Tasks"], responses: { 200:... } } })`
2. **CRUD routes** — `.get()/.post()/.put()/.delete()` for Tasks, Documents, Decisions, Milestones, Config (labels + authors) all follow same boilerplate pattern with `detail` blocks

Approach: Extract a `bulkRoute(path, handler, meta)` and `crudRoutes(resource, handlers)` factory to collapse the repeated patterns. Keep Swagger documentation intact (all `summary`/`description`/`responses` must be in English per AGENTS.md conventions).

Files: `src/server/router.ts`
