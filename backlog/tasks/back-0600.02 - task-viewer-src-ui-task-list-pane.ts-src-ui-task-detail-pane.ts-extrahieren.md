## Schritt 3: task-viewer-with-search.ts — tech-debt Fixes

**Guard Helper** — Ersetzt 13 Guards (Zeilen 1344-1481):
```typescript
function canHandleKey(): boolean {
  return !modalOpen && !filterPopupOpen && currentFocus !== "filters";
}
```
10× `if (modalOpen || filterPopupOpen || currentFocus === "filters") return;` → `if (!canHandleKey()) return;`
3× `if (modalOpen || filterPopupOpen) return;` → `if (!canHandleKey()) return;` (vereinheitlicht)

**cleanup Helper** — Ersetzt 4 Cleanups (Zeilen 1453, 1470, 1484, 1524):
```typescript
function cleanupViewer(): void {
  searchService?.dispose();
  contentStore?.dispose();

}
```
