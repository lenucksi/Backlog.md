## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Baue eine `<FilterBar>`-Komponente — ersetzt `src/ui/components/filter-header.ts` (661 Zeilen).

API:
```typescript
interface FilterState {
  search: string
  status: string[]
  priority: string[]
  milestone: string | null
  labels: string[]
}

<FilterBar
  filters={filters}
  availableLabels={labels}
  availableMilestones={milestones}
  onChange={(newFilters) => setFilters(newFilters)}
/>
```

Features:
- Search-Input mit Escape-Clear
- Filter-Buttons: Status, Priority, Milestone, Labels
- Button-Zustände: idle (default), active (Filter gesetzt)
- Klick auf Button öffnet Filter-Popup (via Modal)
- Flex-Wrap bei Überlauf (Yoga flexWrap)
- Keyboard-Navigation: ←→ zwischen Buttons, Enter/Space öffnet Popup, ↑↓/Escape zurück zur Liste
- Cursor-Position in Search wird erhalten
- Filter Count Badge: zeigt Anzahl aktiver Filter

Datei: `src/ui2/components/filter-bar.tsx`
Tests: `src/test/ui2-filter-bar.test.ts`

Referenzen: blessed filter-header.ts (661 Zeilen), filter-popup.ts (305 Zeilen), opencode's filter implementation
