## Implementation Notes

### Gotchas
- `validateDependencies` from `task-builders.ts` expects full `Core` type. Must use `as never` cast in `resolveDependenciesFromInput` since the new module should not circular-import from `backlog.ts`.
- `resolveDependenciesFromInput` interface changed from `(task, input: TaskUpdateInput, core: Core)` to `(task, input: { set, add, remove, force }, core: { queryTasks, filesystem })` — the caller now restructures the input.
- `resolveStringListField` consolidates 3 functions (labels/references/documentation) with `caseInsensitive` mode for labels (using `v.toLowerCase()`).
- `appendBlock` and `sanitizeAppendInput` are used internally by `applyClearSetAppendBlock` in the new module, no need for backlog.ts to import them.
- `acceptanceCriteria` and `definitionOfDone` resolvers stay separate (for BACK-0599.09 consolidation).
- `TaskQueryOptions` interface defined locally in new module to avoid circular import.
