API-Design:
- Jede Pane-Funktion erhält ein `callbacks`-Objekt statt direkten closure-Zugriff auf let-Variablen

- Die callbacks umfassen: applyFilters, refreshDetailPane, focusTaskList, focusDetailPane, usw.

Wichtigster Grundsatz: Keine let-Variablen in den extrahierten Modulen. Alles per Parameter/Interface.

## Prinzip

Jedes extrahierte Modul bekommt ein `callbacks`-Interface. Die callbacks sind Pfeile zurück in viewTaskEnhanced, die auf die closure-Variablen zugreifen. So vermeiden wir `state.`-Prefix, aber die extrahierten Module haben trotzdem klare Interfaces.

```typescript
// Beispiel: task-list-pane.ts
export interface TaskListPaneCallbacks {
  onSelection(task: Task, selectionId: number): void;
  onBulkSelectionChange(ids: Set<string>): void;
  getFilteredTasks(): Task[];
  getSelectedTaskIds(): Set<string>;
  getCurrentFocus(): "list" | "detail" | "filters";
  setCurrentFocus(focus: "list" | "detail" | "filters"): void;
  setPendingSearchWrap(wrap: PendingSearchWrap): void;
  onRefreshSelectedTask(task: Task): void;
}

export function renderTaskList(
  taskListPane: BoxInterface,
  filteredTasks: Task[],
  currentSelectedTask: Task,
  selectedTaskIds: Set<string>,
  callbacks: TaskListPaneCallbacks,
  createListOptions?: { itemRenderer?: GenericListItemRenderer }
): GenericList<Task> | null
```
