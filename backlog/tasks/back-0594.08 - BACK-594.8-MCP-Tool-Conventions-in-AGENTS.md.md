## Problem

AGENTS.md hat keine MCP Tool Conventions. Die MCP-Tools in `src/mcp/tools/` haben Patterns für Dateinamen, Schema-Definition, Error-Handling und Naming, die undokumentiert sind. Neue Tools werden inkonsistent gebaut.

## Scope

MCP-Patterns aus `src/mcp/tools/` extrahieren und als neuen Section in AGENTS.md dokumentieren.

## Location

AGENTS.md — neuer Section zwischen Code Standards und Git Workflow.

## Zu dokumentieren

- Dateinamen: `{domain}-{verb}.ts` (z.B. `task-create.ts`)
- Input-Schema: Jeder Tool-Parameter braucht `description`
- Handler-Signatur: `(ctx: ToolContext, args: Input) => Promise<Output>`
- Error-Handling: Immer `McpError` mit ErrorCode, nie raw throw
- Tool-Naming: backward-kompatibel (alte Tool-Namen als Alias behalten)
- Output-Format: strukturiertes Response-Objekt, kein raw return
