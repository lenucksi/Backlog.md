## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Baue ein generisches Modal-System für opentui/solid.

API:
```typescript
// Promise-basiert
const result = await openModal<string>((close) => (
  <box flexDirection="column">
    <text>Enter name:</text>
    <Input onSubmit={(v) => close(v)} />
  </box>
))

// Confirm-Dialog
const ok = await openConfirm("Task wirklich archivieren?")

// Komponente (für eingebettete Nutzung)
<Modal open={open()} onClose={() => setOpen(false)} title="Help">
  <HelpContent view={currentView} />
</Modal>
```

Features:
- Backdrop (halbtransparente Box, deckt gesamten Screen ab)
- Focus-Trap (Tab/S-Tab zirkuliert innerhalb des Modals)
- Escape schließt das Modal
- Stacking (mehrere Modals übereinander)
- Animation (optional, via Timeline)
- Title-Leiste im Modal-Header
- z-Index Management

Datei: `src/ui2/components/modal.tsx`
Tests: `src/test/ui2-modal.test.ts`
