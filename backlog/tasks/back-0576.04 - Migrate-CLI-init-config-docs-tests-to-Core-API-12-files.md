Migrate CLI init, config, docs, and agents test files. These primarily test CLI commands — many already use `runBacklogCli()` (in-process Commander) which is already fast. The remaining `bun src/cli.ts` subprocess calls need migration.

## Migration Patterns

### `runBacklogCli()` ist bereits in-process — KEINE Migration nötig
```typescript
// Das ist OK und schnell:
const r = await runBacklogCli(["init", "Test", "--defaults", "--integration-mode", "none"], TEST_DIR);
```

### Task create via Core (für tests die tasks via CLI anlegen nur um sie dann zu testen):
```typescript
const core = new Core(TEST_DIR);
await core.createTaskFromInput({ title: "Test Task", description: "Desc" });
```

### Doc create via Core:
```typescript
const core = new Core(TEST_DIR);
// Check core.createDocument() API — exists in src/core/backlog.ts
// Fallback: use filesystem directly
```

### Config via Core:
```typescript
const core = new Core(TEST_DIR);
const config = await core.filesystem.loadConfig();
```

### DESC alias tests (desc-alias.test.ts):
- Tests `--desc` flag on CLI — das ist CLI-spezifisch
- Can create tasks via Core API directly (just set description in input)
- The help text test (`bun ${cliPath} task create --help`) ist CLI-CONTRACT

### INFRA (behalten):
- `git init` + `git config` → `// INFRA: git setup`

### CLI-CONTRACT (behalten):
- Help text tests (`--help` output)
- Error message formatting
- Init wizard interactive tests

## Final Summary

Migrated CLI subprocess calls to in-process runBacklogCli() or Core API in 5 test files:

**config-commands.test.ts** — 9 `$` `bun src/cli.ts config ...` calls → `runBacklogCli()`. Kept `$` for INFRA git setup.

**desc-alias.test.ts** — 3 `$` `bun src/cli.ts task create/edit ... --desc` calls → `runBacklogCli()` (same Commander program, tests the alias in-process). 2 draft create `$` calls → Core API `filesystem.saveDraft()`. Kept help text test as `$` (CLI-CONTRACT).

**description-newlines.test.ts** — 3 `$` `bun src/cli.ts task create/edit --desc` calls → `runBacklogCli()`.

**cli-init-no-git.test.ts** — `initFilesystemOnlyProject` helper → `runBacklogCli()`. 1 flow test task create → `runBacklogCli()`. Kept stdout-format-checking init test as `$` (clack output not captured by runBacklogCli). Kept draft/doc/decision commands as `$` (not supported by runBacklogCli).

**cli-init-claude-default.test.ts** — 2 `$` `init` calls → `runBacklogCli()`.

**No changes needed** in: cli-init.test.ts, cli-docs.test.ts, cli-agents.test.ts, cli-context.test.ts (already using Core API or CLI-CONTRACT), commands-init-cov.test.ts, commands-config-cov.test.ts, commands-task-cov.test.ts (already using runBacklogCli).

All 27 tests pass across modified files. Biome check and tsc type-check clean.
