## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Baue eine `<Button>`-Komponente für opentui/solid.

API:
```typescript
<Button onClick={handleClick} variant="primary">Speichern</Button>
<Button onClick={handleCancel} variant="default">Abbrechen</Button>
<Button onClick={handleDelete} variant="destructive">Löschen</Button>
```

Features:
- `variant`: `"default" | "primary" | "destructive" | "ghost"`
- `onClick`: Mouse-Event-Handler
- `disabled`: Dimmed, kein Klick
- Focus-Indikator: Andere Border-Farbe bei Fokus
- Hover-Effekt: Hellerer Hintergrund bei Mouse-Over
- `autoFocus`: Erhält Fokus bei Mount
- Keyboard: Enter/Space feuert onClick

Datei: `src/ui2/components/button.tsx`  
Tests: `src/test/ui2-button.test.ts`
