## Fehlende Convention-Sections (neu zu schreiben)

### TUI Conventions
- Screen-Struktur: Jeder Screen eigene Datei, `class extends Component`
- Keybindings: Zentrale Key-Map, nicht in Komponenten
- Blessed/Bit-Contribution in `src/ui/contrib/`
- Einheitliches Form/Input-Handling
- Loading/Error via ScreenHelpers

### MCP Tool Conventions
- Dateinamen: `{domain}-{verb}.ts`
- Input-Schema: `description` auf jedem Feld
- Handler-Signatur: `(ctx: ToolContext, args: Input) => Promise<Output>`
- Error: Immer `McpError`, nie raw throw
- Tool-Naming: backward-kompatibel (Alias für alte Namen)
