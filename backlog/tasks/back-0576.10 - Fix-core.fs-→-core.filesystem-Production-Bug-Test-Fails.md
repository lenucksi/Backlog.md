## Problem
Die `Core` Klasse hat KEIN `fs` Property — nur `filesystem`. Trotzdem wird `core.fs` an 27 Stellen genutzt (2× Production, 25× Tests). Runtime-Crash:
```
TypeError: undefined is not an object (evaluating 'core.fs.loadConfig')
```

Commit `9884c807` hat `this.fs` in `ensureConfigMigrated` bereits gefixt — die restlichen Stellen sind der gleiche Bug.
