## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Parent task:** BACK-0589 — Milestone descriptions across all modalities

**DEPENDENCY:** Requires BACK-0589.01 (Core + REST milestone description update) to be done first — needs the extended PUT API and populated MilestoneBucket.description.

**Goal:** Show milestone descriptions in the WebUI milestone card and allow setting/editing descriptions in the Add/Edit modals.

**What exists:**
- `milestoneEntities: Milestone[]` prop already has full Milestone objects with descriptions (from REST API)
- `renderMilestoneCard(bucket, isEmpty)` shows `bucket.label` as `<h3>` — no description
- Add modal: only name input, no description field
- Edit modal: only name input, no description field
- `apiClient.createMilestone(title, description?)` already accepts optional description
- After BACK-0589.01: `apiClient.updateMilestone(id, { title, description })` and `bucket.description` available

**What to build:**

1. **Milestone card description display** — in `renderMilestoneCard()`:
   - After the header row (line 530), before the progress bar:
   - If `bucket.description` is non-empty and not the auto-generated `Milestone: {title}` text, show it
   - Render as: `<p className="mt-1 text-sm text-gray-500 dark:text-gray-400 line-clamp-2">{bucket.description}</p>`
   - Tailwind `line-clamp-2` truncates at 2 lines with ellipsis

2. **Add modal description field** — in the add form (lines 911-942):
   - Add optional `<textarea>` after the name input
   - Local state, passed to `handleAddMilestone`

3. **Edit modal description field** — in the edit form (lines 944-981):
   - Optional `<textarea>` pre-filled from milestoneEntities lookup
   - Submitted via `updateMilestone(id, { title, description })`

**Files to modify:**
- `src/web/components/MilestonesPage.tsx`

**Design notes:**
- Do NOT show auto-generated "Milestone: {title}" descriptions in cards
- Empty string = no display line
- Keep existing layout intact; description is subtle (small, gray, truncated)
