## Problem

Two independent routing layers:

### Layer 1: Bun.serve.fetch() (src/server/index.ts:191-240)
Handles WebSocket upgrade, static assets (/assets/*), root (/), favicon, then delegates.

### Layer 2: Elysia app.fetch() (src/server/router.ts)
Handles all 41+ API routes + SPA fallbacks.

### Consequences
1. Asset shadowing: Bun.serve intercepts /assets/* before Elysia
2. enrichRequest() hack: config handlers mutate Request to add params (router.ts:91-98)
3. WebSocket outside Elysia, though Elysia supports upgrade() natively
4. Request lifecycle split across two systems
5. Debugging complexity: requests pass through 2 routers

## Location
- src/server/index.ts:188-253 (Bun.serve)
- src/server/router.ts:88-366 (Elysia)
