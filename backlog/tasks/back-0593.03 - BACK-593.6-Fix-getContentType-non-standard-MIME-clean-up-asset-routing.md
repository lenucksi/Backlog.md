## Problem

Three issues in asset serving:

### Issue 1: Non-standard MIME type
src/server/index.ts:181:
```typescript
if (path.endsWith(".tsx") || path.endsWith(".ts")) return "application/typescript";
```
application/typescript has no IANA registration. Vite compiles TS to JS, so this path should never be hit - but if it is, the browser cant interpret it.

### Issue 2: Dual /assets/* routes (shadowing)
Bun.serve.fetch() intercepts /assets/* BEFORE Elysia. If a file with the same name exists in both dist/ and project assets, Bun.serve silently shadows Elysia.

### Issue 3: Legacy path prefix checks
The /styles/ and /web/ path prefix checks (lines 218-221) are legacy from pre-Vite era.

## Scope
Fix issues 1 (MIME) and 3 (cleanup). Issue 2 is addressed by 593.10.

## Location
- File: src/server/index.ts
- Lines: 179-186 (getContentType), 217-231 (asset interception)
