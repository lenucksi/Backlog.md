## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
## Problem
`src/mcp/server.ts` Line 59 blockiert den Module-Export mit top-level `await`:
```typescript
const APP_VERSION = await getVersion();
```
Unter `--parallel` crasht jeder parallele Import von `McpServer` mit:
```
ReferenceError: Cannot access 'McpServer' before initialization.
```
Betrifft ~120 Tests in 12 MCP-Test-Files.

## Fix (1 Zeile in 1 File)

### src/mcp/server.ts
```typescript
// VORHER (Zeile 58-59):
const APP_NAME = getPackageName();
const APP_VERSION = await getVersion();

// NACHHER:
const APP_NAME = getPackageName();
const APP_VERSION = getVersionSync();
```
`getVersionSync()` existiert bereits in `src/utils/version.ts`.

## Verifikation
```bash
bun test --parallel --timeout=10000 --path-ignore-patterns='worktrees/*' --path-ignore-patterns='src/test/e2e/*' --path-ignore-patterns='src/test/tui-interactive-editor-handoff.test.ts' --path-ignore-patterns='src/test/runtime-cwd.test.ts' 2>&1 | grep -E 'fail|pass|Ran'
bun run check .
```
Die Anzahl der Failures MUSS nach dem Fix um ~120 sinken (von ~172 auf ~50).
