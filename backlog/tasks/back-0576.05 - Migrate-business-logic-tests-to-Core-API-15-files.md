## Migration Patterns

### Task create mit allen Feldern:
```typescript
const core = new Core(TEST_DIR);
const { task } = await core.createTaskFromInput({ 
  title: "Test", 
  description: "Desc",
  status: "todo",
  priority: "high",
  implementationPlan: "Plan text",
  implementationNotes: "Notes text",
  finalSummary: "Summary",
  labels: ["bug", "ui"],
  assignee: ["@jo"],
});
```

### Task edit mit notes/plan:
```typescript
const core = new Core(TEST_DIR);
await core.updateTaskFromInput("task-1", { 
  implementationNotes: "New notes",
  appendImplementationNotes: ["Additional note"],
  implementationPlan: "New plan",
  clearImplementationNotes: true,
});
```

### Task edit mit final-summary:
```typescript
await core.updateTaskFromInput("task-1", { 
  finalSummary: "Summary text",
  appendFinalSummary: ["Additional"],
  clearFinalSummary: true,
});
```

### Board loading (board-loading.test.ts):
Tests meist Dateisystem-Logik, braucht keine CLI. Tasks direkt via Core API anlegen:
```typescript
const core = new Core(TEST_DIR);
await core.createTaskFromInput({ title: "Task 1", status: "todo" });
await core.createTaskFromInput({ title: "Task 2", status: "done" });
const tasks = await core.filesystem.listTasks();
```
