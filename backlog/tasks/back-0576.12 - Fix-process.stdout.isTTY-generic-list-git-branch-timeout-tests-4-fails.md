## Problem
4 verschiedene kleine Parallel-Bugs.

### Bug A: process.stdout.isTTY global mutation (2 fails)
**File:** `src/test/zz-ui-components-coverage.test.ts` (Zeilen 586-618)
**Problem:** `process.stdout.isTTY = false` direkt im Test-Body — globaler State. Andere Tests (generic-list-selection) lesen isTTY auf Modulebene und kriegen den falschen Wert.
**Symptom:** `selections.length > 0` = 0 (non-TTY mode auto-select funktioniert nicht)

**Fix:** Save/restore isTTY in jedem Test:
```typescript
// VORHER (Zeilen 586-618):
it("handles non-TTY mode for single select", async () => {
  process.stdout.isTTY = false;
  const { GenericList } = await import("../ui/components/generic-list.ts");
  const items = [{ id: "ITEM-1", title: "First" }];
  const selections: Array<unknown> = [];
  const list = new GenericList({ items, onSelect: (selected) => selections.push(selected) });
  expect(selections.length).toBeGreaterThan(0);
  list.destroy();
});

it("handles non-TTY mode for multi select", async () => {
  process.stdout.isTTY = false;
  // ... (same pattern)
});

// NACHHER:
function withMockIsTTY(value: boolean, fn: () => Promise<void>): Promise<void> {
  const orig = process.stdout.isTTY;
  Object.defineProperty(process.stdout, "isTTY", { value, configurable: true });
  try {
    return fn();
  } finally {
    Object.defineProperty(process.stdout, "isTTY", { value: orig, configurable: true });
  }
}

it("handles non-TTY mode for single select", async () => withMockIsTTY(false, async () => {
  const { GenericList } = await import("../ui/components/generic-list.ts");
  const items = [{ id: "ITEM-1", title: "First" }];
  const selections: Array<unknown> = [];
  const list = new GenericList({ items, onSelect: (selected) => selections.push(selected) });
  expect(selections.length).toBeGreaterThan(0);
  list.destroy();
}));

it("handles non-TTY mode for multi select", async () => withMockIsTTY(false, async () => {
  // ... gleiches Pattern
}));
```

### Bug B: generic-list-selection isTTY module-level cache (1 fail)
**File:** `src/test/generic-list-selection.test.ts` (Zeile 3)
```typescript
// VORHER:
const itIfTty = process.stdout.isTTY ? it : it.skip;
```
Das cached isTTY beim MODULE-LOAD. In --parallel kann isTTY zu dem Zeitpunkt falsch sein (Bug A).

**Fix:** Live-Prüfung statt Cached-Variable:
```typescript
// NACHHER: 
const itIfTty = (name: string, fn: () => void) => {
  if (process.stdout.isTTY) {
    return it(name, fn);
  }
  return it.skip(name, fn);
};
```

### Bug C: find-task-in-branches null results (2 fails)
**Files:** `src/test/find-task-in-branches.test.ts` (Zeilen 36-65, 86-116)
**Problem:** Der Test erstellt Mock-Objekte auf Test-Ebene, aber das getestete Modul (`src/core/task-loader.ts`) könnte Module-State haben der in --parallel überschrieben wird.

**Fix:** beforeEach statt it-body für Mock-Setup (isoliert pro describe):
```typescript
// VORHER (inline mock in jedem it):
it("should find and load task from remote branch", async () => {
  const mockTaskContent = `--- ...`;
  const mockGit = { hasAnyRemote: async () => true, ... };
  const result = await findTaskInRemoteBranches(mockGit as GitOperations, "task-123");
  expect(result).not.toBeNull();
});

// NACHHER (beforeEach isoliert):
describe("findTaskInRemoteBranches", () => {
  let mockGitBase: Partial<GitOperations>;
  beforeEach(() => {
    mockGitBase = {
      hasAnyRemote: async () => true,
      listRecentRemoteBranches: async () => ["feature"],
      listFilesInTree: async () => ["backlog/tasks/task-123 - Test Task.md"],
      showFile: async () => `--- id: task-123 ...`,
    };
  });
  // Tests nutzen mockGitBase + individuelle overrides
});
```
