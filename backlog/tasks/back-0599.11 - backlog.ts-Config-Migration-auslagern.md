## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
- ensureConfigMigrated ruft ensureConfigLoaded auf (Zeile 1267) + this._filesystem.configFilePath. ensureConfigLoaded bleibt in Core (lifecycle).
- extractLegacyConfigMilestones liest die config-Datei direkt via filesystem. Das ist keine Mutation — nur lesen + parsen.
- migrateLegacyConfigMilestonesToFiles ist die einzige Schreib-Operation hier: erstellt milestone files + löscht legacy milestones-Block aus config.
- Die 3 Parser sind pure functions — kein Risiko bei Extraktion.
- ensureConfigMigrated könnte auch komplett nach config-migration.ts wandern, wenn man den Callback für ensureConfigLoaded injiziert. Bleibt erstmal in Core für Klarheit.
